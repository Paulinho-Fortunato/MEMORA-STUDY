# MEMORA STUDY

Um aplicativo mobile premium para aprendizagem inteligente, baseado em métodos cientificamente fundamentados como recuperação ativa, espaçamento, método Feynman e elaboração.

## 🎯 Conceito

Sistema pessoal de aprendizagem e memória com funcionalidades offline-first, privado e altamente personalizável.

## 📱 Stack Tecnológico

- **Framework**: React Native (Expo)
- **Storage Local**: SQLite (via `expo-sqlite`)
- **State Management**: Redux Toolkit
- **UI Components**: React Native Paper + componentes customizados
- **Design System**: Baseado em princípios Apple
- **Notificações**: Expo Notifications
- **Ícones**: Lucide React Native

## 📁 Estrutura do Projeto
